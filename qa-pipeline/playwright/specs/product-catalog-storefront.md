## Product Catalog (Storefront) — happy path

### Browse, filter, sort and configure a product
**Seed:** qa-pipeline/playwright/specs/seed.spec.ts
**Steps:**
1. Navigate to the full catalog listing — target: route /products (step_id: hp-01)
2. Observe the desktop filter sidebar — target: aside 'Filters' / 'Category' / 'Price per Unit (₹)' / 'Highlights' / 'Tags' (step_id: hp-02)
3. Expand the truncated category list — target: button 'Show all 8 categories' (step_id: hp-03)
4. Select the 'Business Cards' category radio — target: input[type=radio][name=category] labelled 'Business Cards' (step_id: hp-04)
5. Open the sort dropdown and choose 'Price: Low to High' — target: sort trigger + menuitem 'Price: Low to High' (step_id: hp-05)
6. Read a product card — target: article containing heading 'Standard Business Cards' (step_id: hp-06)
7. Open the product detail page — target: link 'Configure' inside that card (step_id: hp-07)
8. Observe the live pricing summary — target: 'Price per unit' / 'Total for 500 units' (step_id: hp-08)
9. Change a print option — target: SelectableCard '300 GSM Card' (step_id: hp-09)
10. Select a different quantity tier — target: Quantity Pricing row '1,000' (step_id: hp-10)
11. Select a paid turnaround option — target: SelectableCard 'Rush' (step_id: hp-11)
12. Check a delivery pincode — target: input aria-label 'Pincode' + button 'Check' (step_id: hp-12)
13. Return to the catalog and clear every filter — target: button 'Clear all (2)' (step_id: hp-13)

**Expect:** each step's `expected_result` in the plan, verbatim. Lighthouse checkpoints at
`initial_load` (after hp-01) and `final_state` (after hp-13).

## Product Catalog (Storefront) — error paths

err-01 unknown category slug · err-02 unknown product slug · err-03 catalog search with no
matches · err-04 filter combination with no matches ('Eco Friendly') · err-05 /search with no
matches · err-06 header instant search with no matches · err-07 pincode under 6 digits leaves

## Product Catalog (Storefront) — edge cases

edge-01 one-character search query · edge-02 page past the end of the result set · edge-03
result set smaller than one page ('You’ve seen all 11 products.') · edge-04 uncategorised
product's card link · edge-05 mismatched category/product detail URL · edge-06 price-sort
ordering vs. displayed price across the whole catalog · edge-07 category tile count vs.
listed count · edge-09 stray ?category= on a path-scoped category route · edge-10 ?q= on a
category route redirects before the category lookup · edge-13 no failed image requests.

## Not generated — unvalidated edge cases

- **err-13 / "product with no turnaround options"** (`existing_validation: null` for the
  reachability of that state). The only such product is also the only uncategorised one, so
  its detail page has no valid URL — see the plan's `gaps`.
- **min greater than max in the price filter** (`existing_validation: null`). No code swaps or
  rejects an inverted range; asserting a behaviour nothing implements would be a failing test,
  not a finding. Recorded for the Analyzer.
- **notFound() returning HTTP 200 under the dev server** — the rendered UI is correct and is
  what err-01/err-02 assert; the status code is a production-build question, recorded for the
  Analyzer rather than asserted here.
- **Zustand hydration on the wishlist button** — asserted indirectly (hp-06 reads the
  post-hydration `aria-label`), not as a dedicated timing test.
